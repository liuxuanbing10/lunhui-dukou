## 1. 标准定位与适用范围

### 1.1 标准定位
**2.5D 是《轮回渡口》唯一统一的视觉与交互标准。** 它不是"降级妥协"，而是针对本作"坐定审问 + 对话推理"玩法主动选择的风格最优解：以 2D 动态插画与角色立绘保证 AI 生产的可控性与一致性，以**伪 3D 演出**（视差、单一暖光收束、轻量粒子、叠影回响）制造空间沉浸与情绪峰值，规避真 3D 的建模/绑定/光照成本与产能风险。

### 1.2 适用范围（强制对齐）
| 对象 | 说明 |
|---|---|
| **Web 演出层（首期）** | `@lunhui/web` React19 + Vite6 演出层「五件套」：立绘 / 背景 / 动态 / 音效 / 镜头 |
| **未来桌面端** | Tauri / Godot 壳：直接复用 Web 产出的 2D 精灵图集与环境贴图，演出层可替换 |
| **未来移动端** | Capacitor 壳：同 Web 2D 资产，按屏占比降档 |
| **AI 生成资产管线** | 所有立绘/背景/记忆碎片由 AI 生成，经审核 → 规格化入库（见 §6.3） |
| **引擎内容源** | `packages/engine/residents/r*/SOUL.md` 的 `appearance` / `persona` 字段为立绘提示词锚点 |

### 1.3 不适用（明确排除）
- ❌ 真 3D 场景建模（角色/环境网格、骨骼绑定、PBR 光照）
- ❌ 独立引擎重度 3D（全 3D 场景图、实时 GI、物理碰撞演出）
- ❌ 以摄像机自由漫游为卖点的 3D 关卡（与本作"坐定审问"核心无关）
- ⚠️ 例外：未来 Godot 桌面端如需背景做轻量视差位移，仍属本标准范畴，**不**扩展为真 3D。

## 2. 风格基调

### 2.1 氛围关键词
`雨` · `暗调` · `记忆碎片` · `渡口` · `轮回` · `悬疑` · `回响`

### 2.2 情绪曲线（单局 ride）
```
悬疑(审问/试探) ──→ 回响(命中真相/记忆涌现) ──→ 释然(汤主沉默后的释怀/代价)
  冷蓝压暗           暖光收束+叠影            留白+雨声渐弱
```
- **悬疑段**：冷蓝基底 + 收紧 vignette + 粒子雨，信息密度低、留白多。
- **回响段**：命中 `isKey=true` 触发"沉默三秒"，暖光收束到汤碗单一光源，记忆碎片叠影浮现。
- **释然段**：镜头缓缓拉远，雨声与暖光同步渐弱，进入下一碗汤的过渡。

### 2.3 与对标作品的差异点
| 对标维度 | 借鉴对象 | 本作差异点（2.5D 落点） |
|---|---|---|
| 叙事深度 | 极乐迪斯科 / 十三机兵 / AI 梦境档案 | 审问式对话推理，用**立绘微表情 + 沉默三秒**替代长文本沉浸 |
| 情感回响 | 去月球 / 风之旅人 / 艾迪芬奇 | 用**记忆碎片叠影回响**做"失重回响"，而非过场动画 |
| 世界探索 | Outer Wilds（记忆轮回） | 探索发生在对话中，用**视差推拉**模拟空间而非自由漫游 |
| 互动抉择 | Reigns / 隐形守护者 | 抉择落点在"汤"——暖光收束 = 关键抉择的视觉锚 |

## 3. 色彩与光影规范

### 3.1 光源模型（核心）
- **主基底**：雨夜冷蓝光（环境光，低强度、大面积）
- **唯一暖光源**：汤碗暖光（点光源，叙事核心，用于"沉默三秒"收束）
- **记忆碎片光**：琥珀/锈红自发微光，仅在回响段出现
- **暗角（vignette）**：常驻收紧，焦点指向对话角色与汤碗

### 3.2 色彩变量（CSS 变量，对齐 `TECHNOLOGY.md` 手写 CSS 规范）
```css
:root {
  /* 冷蓝基底（待美术微调） */
  --c-base-deep:   #0B1A26;  /* 雨夜最深背景 */
  --c-base-mid:    #16303F;  /* 中景雾蓝 */
  --c-base-fog:    #2C4A58;  /* 远景雾 */
  /* 汤碗暖光（单一光源，待美术微调） */
  --c-warm-core:   #FFB564;  /* 暖光核心 */
  --c-warm-soft:   #F2A65A;  /* 暖光晕染 */
  /* 记忆碎片色（待美术微调） */
  --c-mem-amber:   #D98A3D;  /* 琥珀碎片 */
  --c-mem-rust:    #A8421F;  /* 锈红碎片 */
  /* 文本与界面 */
  --c-text:        #E8EDEA;  /* 主文本（暗底高对比） */
  --c-text-dim:    #9FB2B0;  /* 次文本 */
  /* 主/辅/警示 */
  --c-primary:     #1C3A4F;  /* 主色（冷蓝） */
  --c-secondary:   #6FA8B0;  /* 辅色（青灰雾蓝） */
  --c-warning:     #C0452F;  /* 警示色（锈红，用于危险抉择/红线） */
}
```
> ⚠️ 所有 hex 为**占位值**，标注「待美术微调」。上线前由美术总监在 2–3 套候选中拍板定稿。

### 3.3 对比度与暗角区间
- 文本 vs 背景对比度 **≥ 4.5:1**（正文）、≥ 3:1（大字/UI 标签）——见 §6.5 可访问性。
- vignette 边缘压暗至背景亮度的 **35%~45%**，中心聚焦区保持 ≥ 80% 亮度。
- 冷蓝区饱和度控制在中低（避免赛博朋克高饱和），暖光区允许高饱和点睛。

## 4. 2.5D 伪 3D 演出技法清单（核心）

> 本标准为 2.5D 的执行核心。以下五法均为**可在 Web 演出层（React + CSS/Canvas/轻量 WebGL）实现**的具体技法，不依赖真 3D 引擎。

### 4.1 视差推拉（Parallax Push/Pull）
- **对话常态**：背景分 3 层（远景雾 / 中景渡口 / 近景雨丝），层间视差系数 0.2 / 0.5 / 1.0。
- **推近**：命中关键线索时镜头缓推（`scale 1.0 → 1.08`，时长 700–1000ms，ease-out）。
- **拉远**：释然段缓拉（`scale → 0.96`），时长 1000–1400ms。
- **景深虚化**：近景/远景在非聚焦时 `blur(2–4px)`，聚焦角色层 `blur(0)`。

### 4.2 单一暖光收束（Silence Light）
- **触发**：`pause:true`（引擎 `isKey=true` 命中，见 `CONTENT_ASSETS.md`）。
- **效果**：冷蓝基底与环境光在 300–500ms 内淡出至 ~20%，仅保留汤碗暖光（径向渐变，半径 ~40% 视口），vignette 同步收紧。
- **退出**：沉默三秒结束后 400–600ms 暖光回落，冷蓝回归。

### 4.3 WebGL 轻量粒子雨 + 水面涟漪（着色器，非场景）
- **雨**：GPU 粒子（≤ 1500 粒），片元着色器 procedural 生成，无贴图依赖；密度随"悬疑度"可调（低 400 / 高 1500）。
- **涟漪**：全屏水面层用噪声 + 正弦扰动着色器，命中真相时涟漪强度脉冲式提升一次。
- **预算**：着色器绘制 < 1 个 draw call，不进入真 3D 渲染管线。

### 4.4 记忆回响的抽象体积感（叠影，非建模）
- **失重回响**：用立绘/背景的 **2–3 层半透明叠影**（offset + alpha 衰减 + 轻微 chroma shift）制造"记忆层叠"的体积错觉，而非 3D 建模。
- **碎片浮现**：琥珀/锈红碎片（§3.2）以 `opacity 0 → 0.6`、叠影时长 1200ms 淡入，配合 §4.3 涟漪脉冲。
- **退出**：碎片以 `opacity → 0`、时长 600–900ms 淡出，残留暖光。

### 4.5 立绘微表情 / 光影随对话状态变化
- **立绘分层**：身体层（静态）+ 面部层（微表情 overlay）+ 光影层（受暖光影响）。
- **状态映射**：
  - 常态：`face_neutral`，暖光 100%。
  - 被逼问：眉压低 overlay + 冷蓝边缘光。
  - 命中真相（`pause`）：瞳孔微张 overlay + 暖光骤收（联动 §4.2）。
  - 释然：嘴角 overlay + 暖光回落。
- **实现**：微表情为独立透明 PNG/WebP 序列（见 §6.2 分层规范），由状态机切换，非整图重绘。

## 5. 交互演出规范（含「沉默三秒」标准）

### 5.1 「沉默三秒」标准时序（核心节奏）
触发条件：`engine` 返回 `pause:true`（即 `isKey=true` 命中）。

| 阶段 | 时序（占位，待演出校准） | 动作 |
|---|---|---|
| T0 命中 | 0 ms | 文本输出完成，立绘切 `face_hit` |
| T1 收束 | 0–500 ms | 冷蓝淡出至 ~20%，暖光收束（§4.2），音效渐弱（见音频衔接） |
| T2 沉默 | 500 ms – **2500~3000 ms** | **汤主沉默三秒**：无文本、无输入、镜头微推（`scale 1.04`），记忆碎片叠影淡入 |
| T3 回落 | 3000–3600 ms | 暖光回落，冷蓝回归，允许玩家继续输入 |
| 量化参数 | `SILENCE_MS = 2500~3000`（默认 2800） | 在 `web` 演出层常量可配，A/B 校准 |

### 5.2 打字机文本节奏
- **字符速度**：`28–36 字符/秒`（默认 32）；长句末句降至 22–26 以留呼吸。
- **标点停顿**：句号/问号 `400–500 ms`，逗号 `200–250 ms`，省略号 `600–800 ms`。
- **关键句强调**：命中前一句可用 `speed × 0.7` + 暖光微闪一次。

### 5.3 记忆回响转场
- **淡入**：`opacity 0 → 0.6`，时长 1200 ms（叠影层）。
- **停留**：1200–2000 ms（随记忆重量可调）。
- **淡出**：`opacity → 0`，时长 600–900 ms。
- **衔接**：转场期间禁用打字机与输入，转场结束回到 §5.1 时序。

### 5.4 音频衔接（占位，待音频标准定稿）
- 沉默三秒期间：BGM/环境音 **渐弱至 15%~20%**，`SILENCE_MS` 内维持；
- 暖光收束同步触发一次低频"心跳/水声"点；
- ⚠️ 具体音频标准由音频负责人另文定义，本标准要求演出层预留 `onSilenceStart / onSilenceEnd` 钩子。

### 6.3 AI 生成 → 审核 → 规格化入库管线
```
[1] 锚点抽取   SOUL.md(appearance/persona) + 章节需求 → 生成提示词（含风格锁：冷蓝基底/暖光/暗角）
[2] AI 生成    本地/云端生成原图（多候选 3–5 张）
[3] 美术审核    对照 §8 风格一致性清单，淘汰偏离项（标注原因）
[4] 规格化      裁剪至档位分辨率、分层（身体/表情/光影）、转 WebP、命名入库
[5] 可访问性检  对比度≥4.5:1、色弱模拟通过（§6.5）
[6] 入库登记    更新资产清单（entity-inventory），写入 resources 引用
```
- **风格锁提示词必含**：`2.5D illustration, rain-night muted blue palette, single warm soup-bowl light, heavy vignette, painterly, no 3D render` —— 防止 AI 跑出真 3D 风。

### 6.4 资产清单与审计
- 主资产清单：`design/assets/asset-manifest.md`（或等价 `entity-inventory.md`）逐资产生成「用途/风格/尺寸/格式/动画需求/AI 提示词」。
- 审计项：命名合规、格式合规、尺寸档位、孤立资产（无引用）、缺失引用（引用无文件）。

### 6.5 可访问性（基础要求，非锦上添花）
- **色弱友好**：警示色不依赖红绿区分，辅以图标/形状；提供「色弱模式」切换（降低红绿对比、提升亮度差）。
- **对比度**：正文文本 vs 背景 **≥ 4.5:1**，大字/UI ≥ 3:1。
- **字幕**：所有对白/旁白带字幕，字号可调（≥ 18px 基准，支持 +25%）。
- **减速选项**：提供「演出减速」开关，将 §5 时序整体 ×1.5（沉默三秒、打字机、转场均放缓），照顾阅读/反应慢的玩家。
- **可访问性分级**：目标 **Standard**（基本全覆盖），冲刺 **Comprehensive**（色弱模式 + 完整减速 + 字幕缩放）。UX 规格须引用此分级。

## 7. 多端衔接

### 7.1 原则
**演出层可替换，内核与 2D 资产不变。** Web 产出的 2D 资产是单一事实源（single source of truth）。

### 7.2 Web → Godot / Tauri（桌面）
- 立绘/背景/碎片 WebP → **精灵图集（TextureAtlas）** 打包，Godot `Sprite2D` / `TextureRect` 直接消费。
- 视差/暖光/叠影演出：Godot 端用 `CanvasItem` + `ShaderMaterial` 重写等价效果，参数（视差系数、暖光半径）沿用本标准常量。
- 粒子雨/涟漪：Godot `GPUParticles2D` + 等价 GLSL，复用 §4.3 参数。

### 7.3 Web → Capacitor（移动）
- 同 2D 资产，**按屏占比降档**（背景 1280×720、立绘 720×1280），控制包体与内存。
- 演出参数统一走配置，移动端默认 `SILENCE_MS` 取上限（3000ms）留反应时间。

### 7.4 复用边界
- ✅ 复用：所有 2D 位图、着色器参数、时序常量、色彩变量。
- ❌ 不复用：Web 专属 DOM/CSS 演出代码（Godot 端用原生节点重写，逻辑同构）。

## 8. 验收标准（质量门）

### 8.1 风格一致性检查清单（10 条）
1. [ ] 全场景冷蓝基底 + 暗角常驻，无" daylight/高饱和"偏离帧。
2. [ ] 暖光仅出自汤碗，无第二暖光源（除记忆碎片微光）。
3. [ ] 所有立绘含 `body / face_neutral / face_hit / face_pressed / face_relief / light` 六层，命名合规。
4. [ ] 背景严格三层分离，视差系数 0.2/0.5/1.0 一致。
5. [ ] 命中 `isKey=true` 必触发沉默三秒（`SILENCE_MS` 区间），暖光收束到位。
6. [ ] 记忆回响用叠影实现，无真 3D 建模资产混入。
7. [ ] 粒子雨 ≤ 1500 粒、单 draw call，无贴图依赖。
8. [ ] 所有 hex 取自 §3.2 变量表（或已审批的微调值），无散落硬编码色。
9. [ ] 对白/旁白均带字幕，正文对比度 ≥ 4.5:1。
10. [ ] 资产命名 `_{vN}` 递增、无覆盖、无孤立/缺失引用。

### 8.2 性能预算（占位，待性能基线校准）
| 指标 | 预算（占位） | 说明 |
|---|---|---|
| 首屏时间 | ≤ 2.5 s（4G）/ ≤ 1.5 s（WiFi） | 含首张背景 + 汤主立绘 + 粒子着色器 |
| 首屏资源体积 | ≤ 3 MB | 背景三层 + 1 套立绘六层 + 着色器 |
| 演出包总体积 | ≤ 12 MB | 全居民立绘 + 背景 + 碎片（可懒加载） |
| 并发音频数 | ≤ 8（Web Audio） | 环境音 + BGM + 点效，沉默段渐弱释放 |
| 帧率 | ≥ 60 fps（桌面）/ ≥ 30 fps（移动） | 粒子+视差+叠影综合 |

### 8.3 美术评审节点
- **节点 A（资产入库前）**：单资产对照 §8.1 清单 + 可访问性抽检，美术总监签核。
- **节点 B（单碗汤演出联调）**：沉默三秒 / 视差 / 叠影时序走查，主理人 + 美术 + 音频三方确认。
- **节点 C（Phase 里程碑）**：全量资产风格巡检 + 性能预算复核，输出《风格一致性报告》。
- **偏离处理**：任何资产偏离本标准须标注原因并经美术总监审批，记录入 DECISIONS.md。
