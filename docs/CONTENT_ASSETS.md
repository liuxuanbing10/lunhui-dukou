## 2. 真相表判定规则（引擎消费）

- **命中 isKey=true** → 回答 `direct` + `pause:true`（汤主沉默三秒）；
- **命中 isKey=false** → 回答 `direct`（可给，但语气保留）；
- **未命中任何 fact** → 走 LLM 生成（按 persona + speechStyle + 当前记忆），模式 `deny/silence/rhetoric`；
- **玩家问"真相"本身**（如"你到底是谁"）→ 默认 `silence` 或反问，不直接揭底；
- **红线**：任何生成不得发明真相表之外的"新事实"（防幻觉失控）。

## 3. 第一碗汤（样板：第 1 夜主事件）

```
【汤面】（玩家开场可见）
"雨夜，渡口。你从水里醒来，8 个人站在岸边等你摆渡。
你数了两次——9 个。再数，8 个。
没人承认多出来的那个是谁。"

【汤底】（真相表）
第 9 个"人"是你自己——你每次轮回醒来时，都从水里上岸。
你数到 9 是因为那一刻你还没完全"上岸"。
蓑衣人看到的是你从水里站起来的过程。

【关键事实（isKey）】
k1: 玩家数到 9 是因为把自己算进去了
k2: 玩家每次轮回都从水里醒来（不是床上）
k3: 蓑衣人知道玩家"从水里来"

【判定示例】
"为什么是 9 个？" → 命中 k1 → direct + pause
"我从哪里醒来的？" → 命中 k2 → direct
"蓑衣人知道什么？" → 命中 k3 → direct
"我是谁？" → 未命中 → silence + 反问（"你问倒我了。你该问的是——你为什么会在水里。"）
```

## 5. 质量红线（主创自审）

1. 汤底必须经得起 10 个问题盘问而不崩（自己玩一遍）；
2. "恐怖为皮，情感为骨"——每碗汤至少留一丝情感钩子（D1 决策）；
3. 不写血腥/色情/迷信诈骗（合规红线）；
4. 每碗汤的真相必须与世界观一致（不违背轮回/渡口设定）。
