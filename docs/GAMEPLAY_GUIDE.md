# 《轮回渡口》玩法说明（怎么玩，从零讲起）

> 版本：v1.0 · 对应当前可玩的第一夜（Phase 1）
> 读这份文档之前，你不需要懂任何世界观设定。读完，你就知道怎么玩。

---

## 一、这是什么游戏（一句话）

**你扮演一个"摆渡人"，在一个永远下雨的渡口小镇醒来。镇上有 8 个居民，每人藏着秘密。你通过"提问"逼问他们，推理出真相。但你每夜都会死，死后轮回——带着记忆重来，世界已经因你而变。**

核心体验：**海龟汤式的悬念追问 × 狼人杀式的套话审问 × 一个会记住你的活小镇。**

---

## 二、你扮演谁 / 游戏目标

- **你**：从水里醒来的人。你不记得自己是谁，不记得为什么在水里。
- **当前目标**（第一夜）：弄清一个最基本的谜——**"船上 9 个人，数完只有 8 个，多出来的那个是谁？"**
- **长远目标**（后续版本）：拼出你自己的身世——你是谁、渡口是什么、为什么所有人都在等你。

**没有血条、没有装备、没有关卡分数。你的武器只有一样：提问。**

---

## 三、核心循环（一局是怎么转的）

```
醒来（渡口） → 观察（8 个居民在镇上） → 选一个人 → 提问 → 得到回答
    → 追问（共 10 次机会） → 挖出关键真相 → 被迫做选择 → 死亡
    → 轮回（带着记忆重来） → 发现世界变了 → 继续推理…
```

每一局（一夜）的核心就一句话：**用 10 个问题，从 8 个藏着秘密的人嘴里，撬出真相。**

---

## 四、具体怎么操作（一步步）

### 第 1 步：打开游戏，看开场白

你从水里醒来。屏幕中央出现一段话：

> 雨夜。你从水里醒来。8 个人站在岸边，等你摆渡。你数了两次：9 个。再数，8 个。没人承认多出来的那个是谁。

**这是本夜要解的谜。** 先记住："多出来的那个人"是谁。

### 第 2 步：选一个居民对话

屏幕下方有 8 个可点的名字（每个带一个符号）：
蓑衣人 🌧️ / 阿岚 🌸 / 老王 🍜 / 阿黎 🪁 / 何叔 🕰️ / 老鲞 ⛵ / 郑爷 🏮 / 小满 🧒

点一个名字选中，然后在输入框打字提问，按回车或点"问"。

### 第 3 步：提问，看回答

你问什么，对方就答什么（或者……不答）。

**举例（真实可复现）**：
- 你问阿岚："多出来的那个人是谁？" → 阿岚低头摆弄白花："石阶上……那个位置，是给没等到的人的。"（目光往渡口扫）
- 你问老王："多出来的那个人是谁？" → 老王："那个人……我不认识，但总想给他添碗面。他去渡口了。"
- 你问蓑衣人："你捞过我吗？" → **蓑衣人停住了。**（画面沉默三秒）"蓑衣人捞过你 7 次。"

**注意这个"停住了"**——当你问到关键事实时，对方会沉默。**沉默 = 你问对地方了。**

### 第 4 步：追问，直到挖出关键

你有 **10 个问题的额度**（屏幕显示"本轮回剩余问题：X / 10"）。

- 问得准 → 对方停顿、破防、给你关键线索；
- 问得泛 → 对方敷衍或沉默；
- 问"你是谁 / 渡口是什么"这种终极问题 → 对方闭口不谈（**真相要你自己拼，没人会直接告诉你**）。

### 第 5 步：关键真相出现 → 被迫选择

当你命中关键事实（比如蓑衣人"捞过你 7 次"），画面变成抉择：

> 水涨了。渡口的船要靠岸。蓑衣人站在河边，看着你。他问："你要上船吗？"

两个选项，**都有代价**：
- **上船**——我想离开这个镇子 → 船在河心沉没，你死了；
- **留下**——我得先弄清我是谁 → 你留不住，你本来就属于水里，你死了。

### 第 6 步：死亡 → 轮回 → 记忆

你死了。但这不是结束，是**轮回**。

- 画面提示："你又上船了。第七次了。"（或"你留下来，也留不住。"）
- 点击"从水里醒来" → 开启新的一夜；
- **这一夜不同**：你带着上一夜的记忆（屏幕显示"你记得：蓑衣人提到：蓑衣人捞过玩家 7 次"）。
- **而且世界变了**——第一夜你审问的蓑衣人，这一夜……你数人数，发现他不见了。

**这就是游戏的钩子：你记得的东西，世界会回应你。**

## 五、提问的艺术（怎么问才有效）

这是游戏的核心技巧，主创先记下，以后写新手引导也用它：

| 问法 | 效果 | 例子 |
|---|---|---|
| **问具体事实** | ✅ 最容易命中 | "你捞过我吗？"（而不是"你是谁"） |
| **问是/否** | ✅ 判定最准 | "你认识我吗？" |
| **重复追问** | ⚠️ 试探底线 | 阿岚被问急了会"信了。她不信。她第二天还问。" |
| **问终极真相** | ❌ 对方沉默 | "你是谁？""渡口是什么？" |
| **问别人的事** | ❌ 对方岔开 | 问阿岚"老王为什么多煮面"→ 她不会答 |

**核心原则：真相藏在具体事实里，不在哲学问题里。** 你越具体，对方越难闪躲。

---

## 六、规则速查表

| 规则 | 值 | 说明 |
|---|---|---|
| 每夜提问额度 | **10 次** | 用尽即强制进入选择阶段 |
| 回答类型 | direct / deny / silence / rhetoric | 直接答 / 否认 / 沉默 / 反问 |
| 关键事实命中 | pause（沉默三秒） | 最强信号：你问对地方了 |
| 选择 | 上船 / 留下 | 都有代价，都会死，但台词不同 |
| 死亡 | 必死 | 第一夜是"必死局"，死是设计不是失败 |
| 轮回 | 无限 | 每轮回记忆衰减（旧记忆变淡，重要记忆永存） |
| 记忆 | 会保留 | 你记得的东西，下一夜的世界会回应 |

## 七、当前能玩到什么（诚实说明）

**当前版本（Phase 1）能完整玩通"第一夜"**：
✅ 开场钩子（9 vs 8） → ✅ 8 个居民 → ✅ 提问/回答 → ✅ 剧情引导（问"多出来的是谁"会有人指路） → ✅ 蓑衣人关键审问（"我捞过你"） → ✅ 上船/留下选择 → ✅ 死亡/轮回 → ✅ 记忆保留

**还没接上的（下一步）**：
- ⏳ **LLM 自由对话**：目前没命中真相表的问题，居民只会"沉默/引导"；接 LLM 后他们会真正"像人一样说话"；
- ⏳ 8 个居民各自完整的审问线（目前只有蓑衣人可深审）；
- ⏳ 立绘/音效（目前是 emoji + 文字占位）；
- ⏳ 多人/连载/付费（变现阶段）。

**结论：现在的版本足够你"亲手玩一遍，验证自己想不想玩第二夜"——这正是 Phase 1 的验收标准。**

## 八、主创自测指引（你怎么验证这游戏立起来了）

1. 终端 A：`cd packages/server && npm run dev`（后端 8787）
2. 终端 B：`cd packages/web && npm run dev`（前端 5173）
3. 浏览器打开 `http://localhost:5173`
4. 按第四节的步骤走一遍：
   - 问老王"多出来的那个人是谁？" → 应指向渡口；
   - 选中蓑衣人，问"你捞过我吗？" → 应"停住了"（沉默三秒 + 关键线索）；
   - 选"上船" → 应显示"船在河心沉没……第七次了"；
   - 点"从水里醒来" → 应显示记忆"蓑衣人提到……"。

**如果这四步都走通，第一夜就立起来了。** 你作为主创玩完这四步，问自己一个问题：**"我想玩第二夜吗？"** ——这就是全部验收标准。
