# 决策记录（定稿）

> 记录影响产品/架构的关键决策。每条含：背景、选项、选择、理由。新增决策须追加。
> 状态：v1.0

## D1. 内容尺度：恐怖为皮，情感为骨

- **背景**：世界观有"细思极恐"底子，需定恐怖/情感配比。
- **选项**：A. 恐怖为主；B. 恐怖为皮、情感为骨（吓完还感动，如《纸嫁衣》）。
- **选择**：B ✅
- **理由**：留存更好（恐怖是钩子，情感是留存）；更贴主创文字优势；合规风险更低（不靠血腥猎奇）。

## D2. LLM 成本预算：每月 ¥0-30（严格限流）

- **背景**：LLM API 是长期产品"油钱"，决定产品规模。
- **选项**：A. ¥0-30（免费网关/DeepSeek 为主，严格限流）；B. ¥30-100；C. 先不设限。
- **选择**：A ✅
- **理由**：主创为学生，现金流优先；DeepSeek 成本极低（百万 token 数元）；倒逼产品设计精简调用（缓存/复用/降采样）。

### D2 派生约束（必须遵守）

1. **每玩家每夜 LLM 调用上限**：≤ 12 次（10 问 + 2 冗余）；
2. **回答缓存**：同一 (question, resident, loop) 命中过则复用，不再调 LLM；
3. **降采样策略**：非关键问题可走免费网关；关键判定走 DeepSeek；
4. **每日熔断**：日成本达阈值（如 ¥3）触发"俭省模式"（默认回答库 + 少生成）；
5. **真相表优先**：能命中真相表的判定**不调 LLM**（纯规则），LLM 只处理自由生成。

## D3. 首发语言：纯中文

- **背景**：目标市场/文案质量。
- **选项**：A. 纯中文（最快）；B. 中英双语（慢，打开全球）。
- **选择**：A ✅
- **理由**：先打本土市场验证；主创母语是中文（文字质量最高）；国际化留到 Phase 3。

## D4. 产品形态：网站（Web）而非软件

- **背景**：用户获取/部署/合规/迭代速度。
- **选择**：Web（React + Fastify）✅
- **理由**：发链接即玩（冷启动友好）；部署即更新；"网页内容"定性地"游戏软件"合规风险低；后端统一跑 LLM（用户免配置）。后期可 PWA/Capacitor 打包升级。
- **⚠️ 已被取代（见 [DESKTOP_MIGRATION.md](DESKTOP_MIGRATION.md) D.A.）**：2026-08-21 主创确认转 **Windows 桌面游戏**（Godot 客户端 + 云端 AI 后端），D4 的 Web 形态由 D.A. 替代；**云 AI 后端由 `@lunhui/server` 承担**（这点 D4 的"后端统一跑 LLM"认知仍然成立）。

## D5. 变现：免费完整 + 内容订阅 + 自愿打赏（不做强制内购）

- **选择**：免费完整体验，付费买"更多/抢先/番外"，自愿打赏 ✅
- **理由**：合规（非游戏内购定性）；口碑；订阅是网文验证过的逻辑。
