# 2.5D 视觉打磨验收清单（Visual Polish Checklist）

> **轮回渡口**（Lunhui Dukou）· Phase 1/P2 演出打磨质量门
> 关联标准：`docs/art-style-standard-2.5d.md`（§3–§8）
> 维护：美术总监（art-director）｜ 本清单所有数值为**量化区间占位**，上线前由对应验收人校准定稿。

| # | 打磨项 | 量化区间占位 | 由谁验收 |
|---|---|---|---|
| 1 | **雨夜冷蓝基底纯度** | 冷蓝区饱和度中低；全场景无 daylight/高饱和跑色帧；`<span style>` 非暖光色中饱和 ≤ 45% | 美术总监 |
| 2 | **粒子雨密度** | GPU 粒子 400（低悬疑）~1500（高悬疑）；单 draw call；无贴图依赖；密度随悬疑度线性可调 | 技术美术 / 工程 |
| 3 | **暖光半径（Silence Light）** | 径向渐变半径 ≈ 40% 视口（±5% 可调）；汤碗为唯一暖光源，边缘羽化 ≥ 60px | 美术总监 + 演出 |
| 4 | **暖光收束曲线** | 冷蓝淡出至 ~20%，时长 300–500ms（ease-out）；沉默结束后回落 400–600ms | 演出导演 |
| 5 | **沉默三秒时长** | `SILENCE_MS = 2500~3000ms`（默认 2800）；命中 `isKey=true` 必触发；期间禁输入/禁打字机 | 主理人 + 美术 |
| 6 | **记忆叠影时长** | 淡入 1200ms（opacity 0→0.6）；停留 1200–2000ms；淡出 600–900ms；2–3 层叠影 + 轻微 chroma shift | 美术总监 |
| 7 | **文本对比度** | 正文 vs 背景 ≥ 4.5:1；大字/UI 标签 ≥ 3:1；色弱模式下降红绿依赖、升亮度差 | 可访问性负责人 |
| 8 | **vignette 收紧** | 边缘压暗至背景亮度 35%~45%；中心聚焦区 ≥ 80%；常驻、焦点指向对话角色与汤碗 | 技术美术 |
| 9 | **首屏预算** | 首屏 ≤ 2.5s（4G）/ ≤ 1.5s（WiFi）；首屏资源 ≤ 3MB；≥ 60fps（桌面）/ ≥ 30fps（移动） | 性能基线 / 工程 |
| 10 | **立绘微表情与暖光联动** | 立绘六层齐备（body/face_neutral/hit/pressed/relief/light）；暖光 100%↔骤收随沉默状态机切换；预留 `onSilenceStart/End` 钩子 | 美术总监 + 音频 |

## 使用说明
- 每项验收前先跑对应演出片段（沉默三秒 / 视差推拉 / 记忆回响），对照上方量化区间走查。
- 偏离区间须标注原因并经美术总监审批，记录入 `DECISIONS.md`。
- 与 §8.1 风格一致性清单互为补充：本清单偏「数值打磨」，§8.1 偏「一致性门禁」。
