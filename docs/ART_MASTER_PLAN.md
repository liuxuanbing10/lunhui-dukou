## 1. 美术风格定位与参考标杆定义

### 1.1 风格定位（一句话）

> **雨夜写实电影 × 单光源戏剧**：冷蓝压暗的渡口雨夜为底，汤碗暖光为唯一叙事光源，
> 用立绘微表情与沉默留白演戏——不炫技、不堆料，每一笔都服务于"审判与释然"的情绪曲线。
> （2026-08-11 主理人拍板：风格由「水墨厚涂」改为「写实电影感数字绘画」，以 r1 蓑衣人首版为方向基准。）

三个不可动摇的风格锚（偏离即回炉）：
1. **冷蓝基底 + 唯一暖光源**——全场景只有汤碗一处暖光（记忆碎片微光除外）；
2. **写实电影感数字绘画，不二次元、不卡通**——AI 风格锁的核心措辞；
3. **留白优先**——信息密度低于市面同类，暗角与雾是构图工具，不是遮丑布。

### 1.2 标杆矩阵（借鉴什么 / 不学什么 / 我们的落点）

| 标杆作品 | 量级 | 借鉴维度 | 我们不学的 | 本作落点 |
|---|---|---|---|---|
| **极乐迪斯科** | 3A 叙事 | 油画质感立绘的"人格即画面"；思想具象化 | 海量文本堆砌 | 立绘微表情六层 + 沉默三秒替代长文本 |
| **Gris** | 独立标杆 | 色彩即情绪曲线（单色→全彩的弧光） | 平台跳跃演出 | 悬疑冷蓝→回响暖光→释然留白的三段色弧 |
| **风之旅人** | 3A 情感 | 单一光源的语言学（光=希望） | 3D 漫游 | 汤碗暖光收束 = 全作唯一"光的一句话" |
| **隐形守护者** | 真人/静帧 | 静帧演出靠微表情与节奏撑住张力 | 真人拍摄成本 | 六层立绘 overlay 切换演静帧戏 |
| **纸嫁衣 / 江南百景图** | 国风商业 | 中国元素不堆砌符号、用色克制 | 民俗猎奇 | 渡口/汤碗/纸人意象走克制路线 |
| **明日方舟 UI** | 商业 UI | 机能风 UI 的秩序感与留白 | 重装饰 | UI 走"渡口文书"极简风：衬线标题 + 冷蓝灰阶 |

### 1.3 标杆量化定义（"达到标杆水平"的可测量解释）

不追求与 3A 拼资产量（AI 生产拼不过），追求**单位画面的情绪密度对标**：

| 指标 | 行业标杆水位 | 本作验收线 |
|---|---|---|
| 首屏截图"可截图传播率"（盲测 10 人愿设为壁纸的比例） | 极乐迪斯科/Gris 档 ≥ 60% | **≥ 40%**（2.5D 产能下的合理线） |
| 角色立绘辨识度（打乱顺序认出角色 ≥ 80%） | 名作标配 | **≥ 80%**（靠剪影+色签，不靠细节堆料） |
| 情绪曲线感知（玩家能说出"何时最安静"） | 风之旅人档 | 盲测命中率 **≥ 70%** |
| 风格一致性（10 条清单通过率） | — | **100%**（硬门禁，见 §4） |

## 2. 资产生产管线与规范

### 2.0 总原则：纯 AI 生产 + 人工审核闸门 + 工程化后处理

> 用户已拍板：纯 AI 生产策略不变。人工只做三件事：**定锚点、做审核、调参数**。
> 自动化率目标：**生成/后处理 ≥ 85% 自动化，人工时间 100% 花在审核与审美决策上**。

### 2.1 四条生产线（角色 / 场景 / UI / 特效）

#### 线 A：角色立绘（8 居民 × 六层规格）

| 环节 | 工具 | 自动化% | 人工做什么 |
|---|---|---|---|
| 锚点抽取 | `SOUL.md` appearance/persona → prompt 模板 | 90%（脚本） | 校对性格→外貌映射 |
| 生成 | ImageGen（主）；备选本地免费图像模型 | 100% | 无 |
| 候选筛选 | 每角色出 4–6 张候选 | — | **人工 30 秒/张淘汰赛**（风格锁符合度） |
| 分层（身体/表情/光影） | prompt 要求透明底 + ImageMagick 合成校验 | 70% | 对齐微表情 overlay（眼/嘴位置） |
| 规格化入库 | ImageMagick：裁剪 1080×1920 → WebP q82 | 100%（脚本） | 无 |
| 质检 | §4 自动检查（尺寸/命名/alpha）+ 人工风格审 | 50% | 对照 §8.1 清单签核 |

**六层规格**（标准 §6.1 强制）：`body / face_neutral / face_hit / face_pressed / face_relief / light`。
**单角色成本**：约 30–40 次生成（含废稿）≈ 150–400 credits；人工约 40 分钟。

#### 线 B：场景背景（渡口雨夜，三层视差 plate）

| 环节 | 说明 | 自动化% |
|---|---|---|
| 构图锚点 | 远雾 / 中景渡口 / 近景雨丝三层分绘，视差系数 0.2/0.5/1.0（标准 §4.1） | 提示词模板化 |
| 生成 | ImageGen 出 2560×1440 原图，每层 4 候选 | 100% |
| 接缝与透视修正 | ImageMagick 拼接 + 人工笔刷修补接缝（AI 图最大坑） | 30%（人工为主） |
| 规格化 | 切 1920×1080 @1x 交付档 → WebP | 100% |

**单场景成本**：3 层 × 4 候选 × 2 轮迭代 ≈ 24 次生成 ≈ 120–240 credits；人工约 1.5 小时（接缝是主要人工项）。

#### 线 C：UI（渡口文书风，SVG 优先）

- **策略**：UI **不走 AI 生图**——AI 生 UI 图标一致性差、边缘脏，SVG 手写/组件库更可控。
- **选型（不造轮子）**：
  - 图标：现成线性图标集改色（Lucide 风格）→ 统一描边 1.5px / 冷蓝灰阶；
  - 字体：思源宋体（衬线标题）+ 思源黑体（正文），开源免授权风险；
  - 组件：现有手写 CSS 变量体系（`--c-*`）不动，只补图形层。
- **交付物**：图标集 ≈ 16 枚、字幕底、按钮三态、问答输入区视觉、色弱模式开关。
- **成本**：≈ 0 credits，人工约 2–3 小时（可由工程侧代劳）。

#### 线 D：特效（程序化为主，贴图最小化）

| 特效 | 实现 | 说明 |
|---|---|---|
| 粒子雨 / 涟漪 | GLSL 着色器（标准 §4.3） | **已有**，只做密度/脉冲调参 |
| 暖光收束 | 径向渐变 + CSS/Canvas 混合 | **已有**，调半径/羽化参数 |
| 记忆叠影 | 立绘半透明 ghost 层 × 2–3（AI 生成琥珀残影 2–3 张） | 新增少量资产 |
| 胶片颗粒/暗角 | 片元着色器程序化 | 新增，零贴图 |

**原则**：特效预算的 80% 花在调参上，不花在贴图上——程序化特效才能全端复用（Godot/移动端同参数迁移）。

### 2.2 一致性纪律（"不假"的灵魂，强制项）

1. **调色板锚定**：所有 prompt 必须引用 `theme.ts` 实际值（`rain.base #0b1a2b` / `warm.soul #ffb15c` / `memory.amber #d8a24a`），禁止凭感觉写颜色词；
2. **风格锁措辞**（写入每个 prompt 尾部）：
   `cinematic photorealistic digital painting, film concept art, rain-night muted blue palette, single warm soup-bowl light, heavy vignette, film grain, not anime cel-shading, not cartoon, no flat illustration`；
3. **角色色签**：每居民绑定 1 主色 + 1 辅色（剪影可辨），写入 SOUL.md 并注入该角色全部 prompt；
4. **版本纪律**：`{类型}_{对象}_{变体}_v{N}.webp`，只递增不覆盖，废稿进 `refs/` 留档。

## 3. 关键技术选型与性能预算

### 3.1 技术选型（全部已验证或已在栈内，零新轮子）

| 决策点 | 选型 | 理由（对比项） |
|---|---|---|
| 渲染层 | 保留 R3F 演出层（不引入 PixiJS/Phaser） | 已跑通 70/70，懒加载已解决包体；换引擎是纯负收益 |
| 资产格式 | WebP q82（立绘透明层 PNG 兜底） | WebP 比 PNG 小 60–70%；q82 是质感/体积拐点 |
| 懒加载 | 按居民懒加载立绘六层（React.lazy 已铺好路） | 首屏只载当前汤主；其余进 `IntersectionObserver` 预热队列 |
| 后处理 | ImageMagick（本地已装 `D:\tools\ImageMagick`） | 免费、脚本化、够用；不上 Photoshop 管线 |
| 生成工具 | ImageGen（主）+ 本地免费模型（兜底） | 成本可控；本地模型零成本但需确认本机配置 |
| UI 图形 | SVG + 开源图标改色 | 见 §2.1 线 C |

### 3.2 性能预算（硬数字，接入后逐条回归）

| 指标 | 预算 | 当前基线 | 备注 |
|---|---|---|---|
| 首屏 JS | ≤ 250KB raw / ≤ 80KB gzip | 204KB / 66KB | 美术不得进首屏 JS 关键路径 |
| 首屏图片资源 | ≤ 1.5 MB | 0 | 背景三层(≤600KB) + 汤主立绘(≤400KB) + 汤碗道具 |
| 单张背景层 | ≤ 250 KB (WebP) | — | 超标必须降 q 或分辨率，无豁免 |
| 单立绘身体层 | ≤ 350 KB；表情 overlay ≤ 90 KB/张 | — | 六层合计 ≤ 800 KB/居民 |
| 演出包总体积 | ≤ 12 MB（全居民 + 全背景，懒加载） | — | 标准 §8.2 原值，维持 |
| 帧率 | ≥ 60 fps 桌面 / ≥ 30 fps 移动 | 已达标（程序化层） | 接入贴图后需重测 |
| 首屏时间 | ≤ 2.5s (4G) / ≤ 1.5s (WiFi) | JS 部分达标 | 图片接入后 Lighthouse 实测 |

**预算执行机制**：vite build 产物体积写进 CI 断言（`build.chunkSizeWarningLimit` 已设 800，另加资产体积脚本检查），超预算 = 构建红，不许"先合后治"。

## 4. 质量检验标准

### 4.1 三道质检门（资产生命周期）

```
门 1 候选淘汰（生成后）   → 门 2 入库签核（规格化后）   → 门 3 演出联调（接入后）
   风格锁符合度盲筛            §8.1 十条清单 + 自动化检查        沉默三秒/视差/叠影走查
   人工 30s/张                 美术总监签核                      主理人+美术+音频三方
```

### 4.2 门 2 自动化检查项（脚本实现，进 CI）

- [ ] 尺寸档位匹配（背景 1920×1080 / 立绘 1080×1920 / UI @2x）；
- [ ] 命名规范 `{类型}_{对象}_{变体}_v{N}` 且无覆盖；
- [ ] WebP 编码 + 体积 ≤ §3.2 档位上限；
- [ ] 透明层 alpha 通道存在且无白边残留（边缘像素抽检）；
- [ ] 立绘六层齐备（缺一不入库）；
- [ ] 对比度 ≥ 4.5:1（文本压图区域自动取色计算）；
- [ ] 色弱模拟通过（红绿信息不依赖单一色相）。

### 4.3 AI 伪影专项检查（行业血泪清单，人工 20s/张）

手指/手部畸变、文字乱码（AI 最爱在招牌上写字）、边缘融合脏、光源方向与汤碗不一致、
透视塌缩、风格跑偏（出现赛璐璐/写实/3D 质感）——**任中一项直接废稿，不修补**（修补成本 > 重生成）。

### 4.4 里程碑评审节点（对齐标准 §8.3）

| 节点 | 时机 | 内容 | 产出 |
|---|---|---|---|
| A | 每批资产入库前 | 门 1+门 2 | 签核记录 |
| B | 单碗汤演出联调 | 沉默三秒/暖光/叠影时序走查 | 三方确认单 |
| C | 每个 M 里程碑结束 | 全量风格巡检 + 性能回归 + 盲测 | 《风格一致性报告》 |
| 偏离处理 | 随时 | 偏离须标注原因 + 美术总监审批 | 记入 DECISIONS.md |

## 5. 分阶段实施路线（对齐 ROADMAP Phase 1–3）

> 排期假设：AI 生成 + 单人审核模式（当前现实）。人天为"人工审核+决策"时间，生成时间不计。

### M1 · 去假垂直切片（≈ Phase 1 内，2–3 周）——**本规划的启动点**

**目标**：何叔（r5-heshu）这一碗汤，从"活但假"变"真且活"。证明管线成立，而非铺量。

| # | 交付物 | 数量 | 成本（credits） | 人工 |
|---|---|---|---|---|
| M1-1 | 渡口雨夜背景三层 plate（远/中/近） | 3 层 | 120–240 | 1.5h（接缝） |
| M1-2 | 何叔立绘六层 | 6 张 | 150–400 | 40min |
| M1-3 | 汤碗暖光道具（透明 PNG，替换 R3F 光球） | 1 张 | 20–50 | 15min |
| M1-4 | 记忆叠影 ghost 残影 | 2–3 张 | 40–90 | 15min |
| M1-5 | 接入：背景替程序天空、立绘替占位、暖光叠道具 | — | 0 | 2h（工程） |
| M1-6 | 性能基线报告（接入后首屏/帧率重测） | — | 0 | 0.5h |

**验收标准（DoD）**：
1. 门 3 联调通过：命中关键真相 → 沉默 2800ms → 暖光收束 + 何叔 `face_hit` 微表情，三方签核；
2. §4.3 伪影检查零残留；盲测 5 人"真且活"主观评分 ≥ 4/5；
3. 性能：首屏图片 ≤ 1.5MB、帧率 ≥ 60fps、首屏时间 ≤ 2.5s (4G)；
4. 管线脚本（prompt 模板 + ImageMagick 规格化 + 入库检查）全部入库可复跑——**M1 的真正产物是管线，不只是 13 张图**。

### M2 · 全阵容铺量（≈ Phase 2 内，4–6 周）

**目标**：8 居民全量六层 + 全场景 + UI 图形层 + 管线自动化率 ≥ 85%。

|---|---|---|---|---|
| M2-1 | 其余 7 居民立绘六层（复用 M1 管线批量） | 42 张 | 1050–2800 | 4.5h |
| M2-2 | 背景变体（雨势/时辰 2 套变体层） | 4–6 层 | 200–400 | 2h |

| M2-4 | UI 图形层（SVG 图标集 + 字幕底 + 按钮态） | ≈ 20 件 | 0 | 2.5h |
| M2-5 | 资产清单 `asset-manifest.md` + CI 体积/命名/对比度自动检查 | — | 0 | 2h |
| M2-6 | 色弱模式 + 演出减速开关（可访问性 Standard 档） | — | 0 | 1.5h |

3. 演出包总体积 ≤ 12MB，懒加载后首屏不回归（≤ 250KB JS + ≤ 1.5MB 图）；

## 6. 团队分工与排期

> 现实约束：当前为单人 + AI 协作体。职能按 ROADMAP 六角色映射，一人多角，AI 代劳生成与脚本。

## 7. 风险与兜底方案

| # | 风险 | 概率 | 影响 | 兜底方案（Plan B） |
|---|---|---|---|---|
| R1 | **AI 一致性漂移**：同一角色跨图脸崩/风格跑偏 | 高 | 致命（"假"的根源） | ① 角色色签 + 风格锁措辞强制注入；② 每角色先生"定妆图"，后续生成以定妆图为参考；③ 漂移即整批回炉，不修补 |
| R2 | **生成成本/额度超支**（云端额度已出现耗尽先例） | 中 | 中 | ① M1 先跑小预算验证单张成本；② 本地免费图像模型兜底（启动前确认本机配置）；③ 废稿率 > 60% 时停线复盘 prompt 而非加大投放 |
| R3 | **接缝/透视修正人工超预期**（背景三层） | 中 | 中 | ① 背景改"雾遮三层"构图，用雾掩盖接缝；② 兜底：中景单层 + 程序化雾层替代 |
| R4 | **性能回归**：贴图接入后帧率/首屏破线 | 低 | 中 | 预算 CI 硬拦截（§3.2）；兜底降档：立绘降 720p 档、背景 q75 |
| R5 | **AI 内容合规/版权不确定性** | 低 | 高 | ① 提示词与产出全留档（refs/）；② 不使用真人/在世画师风格指向词；③ 发布前做一轮合规自查 |
| R6 | **审美单点**：用户是唯一审美决策人，档期受阻 | 中 | 中 | 门 1 淘汰赛设计为"30 秒/张"低负担操作；AI 预筛把候选压到 ≤ 6 张再呈递 |
| R7 | **风格锁过紧导致候选全灭** | 中 | 低 | 风格锁措辞分级（严格/宽松两档），M1 用严格档，连续 3 批全灭则切宽松档并记录偏离入 DECISIONS.md |

**最终兜底（全线失败时）**：若 AI 原画在 M1 内被证伪（盲测 < 3/5 且 3 轮迭代无改善），
回退"高级程序化"路线：升级着色器（胶片颗粒 + 渐变天空 + 体积雾）+ 强化排版戏剧（大字衬线 + 留白），
保"活且有格调"，弃"真"。该决策点设在 **M1 门 3 联调**，止损上限 = M1 预算。
