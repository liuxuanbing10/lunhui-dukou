## 道路系统（多路径）

1. **东西主干道**：南/北沿河街 × 2（双主干，靠桥互通）
2. **南北通道**：西桥 + 东桥（双桥过河，形成环路）
3. **垂直巷**：南巷 ×3 + 北巷 ×3（连接河街与建筑区）
4. **广场**：渡口码头广场（中央枢纽，汇集 3 条路）
5. **可达性**：任意建筑可经 ≥2 条不同路径到达（环路设计）

## 可行走区域（Walkable Mask，供前端碰撞）

- 允许：沿河街、小巷、广场、桥面、栈桥
- 禁止：水面、建筑占地（含屋檐投影）、支流、绿化
- 实现：前端用多边形/网格 mask（见 `packages/web/src/scene/walkable.ts`），WASD 移动前检测目标点，非法则阻止（贴边滑动）

## 氛围要点

- 雨：斜雨（方向统一 -x 偏角 8°），水面涟漪密集，屋檐滴水
- 雾：薄雾贴水，远景民居虚化
- 灯：檐下灯笼 + 窗灯（暖橙），码头汤碗光为唯一强光
- 声：雨声 + 远处若有若无的笛声（后续音频层）
