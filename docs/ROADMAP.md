# 渡口小镇·写实化路线图（AI 参考图驱动 · 对标现代开放世界）

> 核心方法论：**先出参考图，再动手做**。每个阶段第一步用 Qwen-image 3.0 生成"目标效果参考图"（建筑/人物/氛围），把它作为视觉锚点——材质怎么调、光照怎么打、人物长什么样，全部对照参考图，不做没有参照的盲目制作。每阶段验收 = 实机截图 vs 参考图对比。

---

## 〇、现状诊断（为什么假）

| 维度 | 现状 | 病根 |
|---|---|---|
| 建筑材质 | 纯色 Principled 无纹理 | 无纹理 = 塑料感（写实感 80% 来自纹理） |
| 光照 | 一盏点光无阴影 | 无明暗体积/投影/AO |
| 人物 | 胶囊人形（头球+柱体） | 无骨骼动画/衣料/特征 |
| 雨效 | instanced 直线 | 无粒子/水花/湿表面 |
| 后期 | Bloom/Vignette | 无 ACES 色调/阴影/雾体 |

## 阶段 1：材质写实化（+60% 观感 · 90% 自动化）

**先出图**：R2 民居近景 + R3 石板路 + R4 水面倒影（Qwen 生成，作为调材质时的对照）

| 任务 | 做法 | 对照参考图 |
|---|---|---|
| 1.1 白墙斑驳 | 程序化噪声+水渍纹理（Blender 烘焙 / CanvasTexture） | R2 墙面斑驳明暗 |
| 1.2 黛瓦瓦楞 | 瓦片阵列 + normal map | R2 屋顶瓦楞 |
| 1.3 木构湿木 | 木纹 + roughness 高光 | R2 柱梁湿润感 |
| 1.4 石板湿路 | 青石纹理 + 裂缝青苔 + 湿反光 | R3 |
| 1.5 水面倒影 | 法线波纹 + 灯影镜像 | R4 |

**验收**：实机截图 vs R2/R3/R4 对比，材质层次接近参考图 70%+ 算过。

## 阶段 2：光照系统（+25%）

**先出图**：R1 全景概念图（光照/雾/色调总基准）

| 任务 | 做法 |
|---|---|
| 2.1 ACES 色调映射 | three ACESFilmicToneMapping + 曝光 |
| 2.2 暖光实时阴影 | 汤碗/灯笼点光 shadow map |
| 2.3 半球光体积感 | 天蓝/地暗半球光 + 环境贴图 |
| 2.4 AO 接触阴影 | 烘焙或 SSAO 后处理 |
| 2.5 双层雾 | 贴地薄雾 + 远景浓雾 |

**验收**：实机截图 vs R1，明暗/雾/色调氛围接近参考图。

## 阶段 3：人物升级（+10%）

**先定基准**：r1-r8 body 立绘 = 模型视觉基准（服装配色姿态必须像立绘）

| 任务 | 做法 |
|---|---|
| 3.1 骨骼动画 | Mixamo 人形 + 行走/站立动画（CC0） |
| 3.2 朝向玩家 | 对话时 slerp 转身 |
| 3.3 服装配饰 | 按立绘加特征件（蓑衣斗笠/围裙/哨子/布包/纸人） |
| 3.4 体型参数 | 小满矮/老鲞壮/何叔驼背 |

**验收**：3D 模型 vs 对应立绘对比，轮廓/配色/特征 60%+ 相似。

## 阶段 4：环境氛围（+15%）

**先出图**：R7 雨夜氛围细节

| 任务 | 做法 |
|---|---|
| 4.1 植被 | 垂柳/芦苇/青苔（Poly Haven CC0 / 程序化） |
| 4.2 粒子雨 | 斜雨粒子 + 地面水花 + 湿表面高光 |
| 4.3 屋檐滴水 | 檐口粒子 |
| 4.4 雨云天空 | 多层渐变 + 慢滚 |
| 4.5 音效 | WebAudio 雨声 + 笛音 + 钟鸣 |

GLB 减面 LOD / KTX2 压缩 ≤6MB / 分片加载。

## 优先级与验收纪律

| 阶段 | 提升 | 自动化 | 顺序 |
|---|---|---|---|
| 0 参考图生产 | 锚定全部视觉 | 90% | **第一步** |
| 1 材质 | +60% | 90% | 第二 |
| 2 光照 | +25% | 75% | 第三 |
| 3 人物 | +10% | 65% | 第四 |
| 4 环境 | +15% | 80% | 第五 |

**纪律**：
1. 每阶段先出参考图（Qwen）→ 用户过目确认 → 才动手做
2. 做完截图 vs 参考图对比验收 → 用户确认 → 提交
3. 不盲目开做：没有参考图对照的部分，宁可先不做
4. 四件套（test/lint/typecheck/build）全绿才提交
